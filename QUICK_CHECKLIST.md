### Step 2: Google Search Console (10 minutes)
```
1. Open: https://search.google.com/search-console/welcome
2. Click "Add property"
3. Enter: https://keshri-dev.vercel.app
4. Choose: Domain (easier)
5. Copy the DNS TXT record
6. Go to: https://vercel.com/dashboard
7. Project Settings > Domains > Add DNS Record
8. Paste the TXT record
9. Wait 5-15 minutes
10. Return to GSC and click "Verify"
```

## 🚨 If Something Goes Wrong

### "Verification Failed"
- Solution: Wait 24 hours, try again
- Alternative: Use HTML file method (see GOOGLE_VERIFICATION_SETUP.md)

### "Sitemap has errors"
- Check: Can you visit each URL in browser?
- Fix: Ensure all links are working

### "Blocked by robots.txt"
- Already fixed: Use the robots.txt we created

### "No crawl errors but low traffic"
- This is normal: Takes 4-8 weeks to see real traffic
- Keep monitoring and optimizing
